S-CORE is built across multiple repositories. This guide explains which documentation lives where and helps you find the right path for your work.

HOW THE PROJECT IS ORGANIZED

Documentation follows the work

There is no single repository that contains every implementation detail. Documentation is maintained alongside the project area it describes, while reference integration documents how the pieces work together.

S-CORE platform

Platform concepts, architecture, features, requirements, user guidance, and project plans.

Browse platform docs →

Module repositories

Module-specific implementation guidance and details live with the repositories that own those modules.

Explore S-CORE repositories →

Reference integration

The cross-repository integration baseline brings modules together and documents integration status, workflows, and releases.
